## ADDED Requirements

### Requirement: Root .gitignore file
The repository SHALL contain a root-level `.gitignore` file that excludes Node.js/Electron build artifacts and dependency directories, environment files, OS-generated files, editor-specific directories, and log files from version control.

#### Scenario: Dependency directories are ignored
- **WHEN** a `node_modules` directory exists anywhere under the repository (e.g., `app/node_modules`)
- **THEN** `git status` SHALL NOT report its contents as untracked or stageable

#### Scenario: Build output directories are ignored
- **WHEN** `app/dist` or `app/out` are generated by build or packaging commands
- **THEN** `git status` SHALL NOT report their contents as untracked or stageable

#### Scenario: TypeScript incremental build caches are ignored
- **WHEN** a `*.tsbuildinfo` file is generated (e.g., `app/tsconfig.node.tsbuildinfo`, `app/tsconfig.web.tsbuildinfo`)
- **THEN** `git status` SHALL NOT report it as untracked or stageable

#### Scenario: Environment and OS/editor artifacts are ignored
- **WHEN** a `.env` file, OS-generated file (`.DS_Store`, `Thumbs.db`), editor directory (`.vscode/`, `.idea/`), npm/yarn log file, or `coverage/` directory is present anywhere in the working tree
- **THEN** `git status` SHALL NOT report it as untracked or stageable

### Requirement: Untracking of previously committed build artifacts
The repository's git history SHALL NOT track `app/node_modules`, `app/dist`, `app/out`, `app/tsconfig.node.tsbuildinfo`, or `app/tsconfig.web.tsbuildinfo`, achieved by amending the sole existing local commit (since it has never been pushed to a remote).

#### Scenario: Previously tracked bloat is removed from the commit
- **WHEN** the repository's commit history is inspected after this change is applied
- **THEN** `git ls-files` SHALL NOT list any path under `app/node_modules`, `app/dist`, `app/out`, `app/tsconfig.node.tsbuildinfo`, or `app/tsconfig.web.tsbuildinfo`

#### Scenario: Working-tree files are preserved during untracking
- **WHEN** the untracking step (`git rm --cached`) is performed
- **THEN** the actual files SHALL remain present and unmodified on disk in the working tree
